## 修复静态文件 500 错误（本地资源加载失败）

**问题**：页面显示乱，所有 `/static/` 资源返回 500 错误。

**根因**：`app.py` 第 1481 行的 `@app.after_request` 钩子 `add_cache_headers()` 中，对 Flask 静态文件响应（`direct_passthrough=True` 模式）调用了 `response.add_etag()`，触发 `RuntimeError: Attempted implicit sequence conversion but the response object is in direct passthrough mode`。

**修复**：在修改缓存头之前先判断 `response.direct_passthrough`，若为 True 则直接 return，跳过 ETag/Cache 操作。同时移除了 `response.headers.remove('ETag')` 和 `response.add_etag()` 两行危险调用。

**验证**：修复后所有静态资源均返回 200，Bootstrap/FontAwesome 样式正常加载。
