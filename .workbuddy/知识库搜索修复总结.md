# 知识库搜索显示问题修复总结

## 问题描述
用户报告：知识库全文搜索可用，但是知识库搜索只提示找到多少个文档，没有文档列表显示出来。

## 根本原因分析
经过详细排查，发现问题根源在于：

1. **FTS索引中的标题字段问题**：FTS表 `knowledge_files_fts` 中的 `title` 字段直接存储原始文件名（如 `20260401114329_1faa00c9497b468dad8c514946dffb4c.doc`），这些文件名包含时间戳、UUID等噪音，不适合作为用户界面显示。

2. **搜索结果标题处理不当**：搜索结果显示时，直接使用FTS表中的原始标题，这些标题可能：
   - 包含大量技术性前缀（时间戳、UUID）
   - 没有进行适当的清理和格式化
   - 在某些情况下可能为空或过短

3. **标题高亮逻辑问题**：在高亮搜索词时，如果标题中不包含搜索词，标题可能保持原样显示，对于不友好的文件名，用户体验差。

## 修复措施

### 1. 重建FTS索引
- 重新构建了 `knowledge_files_fts` 全文搜索索引
- 确保所有448条已审核文件都被索引

### 2. 改进搜索结果标题处理
在 `app.py` 的 `search_knowledge_fts` 函数中添加了标题优化逻辑：

```python
# 如果标题为空或太短，尝试从数据库中获取更好的标题
if not title or len(title.strip()) < 3:
    try:
        kf = KnowledgeFile.query.get(row.file_id)
        if kf and kf.original_name:
            title = kf.original_name
        elif kf and kf.filename:
            # 从文件名中提取一个更好的标题
            filename = kf.filename
            # 移除时间戳前缀
            clean_name = re.sub(r'^\d+_', '', filename)
            clean_name = re.sub(r'^\d{14}_', '', clean_name)
            # 移除UUID部分
            clean_name = re.sub(r'_[a-f0-9]{8,}', '', clean_name)
            # 移除扩展名
            clean_name = re.sub(r'\.[a-z]{2,4}$', '', clean_name, flags=re.IGNORECASE)
            if clean_name and len(clean_name) > 2:
                title = clean_name
    except Exception:
        pass
```
