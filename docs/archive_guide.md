# 档案管理系统 - 设计与实现总结

## 📋 档案国家标准概览

### 核心标准

| 标准编号 | 标准名称 | 适用范围 |
|---------|---------|---------|
| **GB/T 18894-2016** | 电子文件归档与电子档案管理规范 | 电子档案全生命周期管理 |
| **DA/T 31-2017** | 纸质档案数字化规范 | 纸质档案扫描、OCR、元数据 |
| **DA/T 18-1999** | 档案著录规则 | 档案目录著录项目与格式 |
| **DA/T 22-2015** | 归档文件整理规则 | 文件分类、编号、装订 |
| **GB/T 11822-2008** | 科学技术档案案卷构成的一般要求 | 科技档案整理 |

### 档案数字化关键要求

#### 1. 元数据标准 (DA/T 18)
```
必备字段：
- 档号：全宗号-目录号-案卷号-件号
- 题名：档案标题
- 责任者：形成单位/人
- 日期：形成日期
- 保管期限：永久/30年/10年
- 密级：公开/内部/秘密/机密/绝密
- 页数/张数
- 关键词/主题词
- 摘要
- 存放位置
```

#### 2. 扫描技术要求 (DA/T 31)
- **分辨率**: 300dpi（普通）、600dpi（珍贵档案）
- **色彩模式**: 黑白/灰度/彩色（根据原件）
- **格式**: TIFF（存档）、JPEG（浏览）、PDF/A（长期保存）
- **OCR识别率**: ≥95%

#### 3. 档案分类体系
```
常用分类方法：
├── 年度-机构-保管期限（文书档案）
├── 年度-类别-项目（科技档案）
├── 专业-年度-项目（专门档案）
└── 全宗号-分类号-案卷号（传统方法）
```

## 📊 数据模型

### 全宗 (ArchiveFonds)
```python
- fonds_code: 全宗号
- fonds_name: 全宗名称
- fonds_type: 全宗类型
- description: 说明
- total_volumes: 案卷总数
- total_files: 文件总数
```

### 目录 (ArchiveCatalog)
```python
- catalog_code: 目录号/分类号
- catalog_name: 目录名称
- parent_id: 父目录（支持层级）
- retention_period: 保管期限
```

### 案卷 (ArchiveVolume)
```python
- volume_code: 案卷号
- volume_title: 案卷题名
- volume_year: 年度
- retention_period: 保管期限
- security_level: 密级
- storage_location: 存放位置
```

### 档案文件 (ArchiveFile)
```python
# 档号体系
- file_code: 件号
- get_archive_code(): 生成完整档号

# 核心元数据（DA/T 18）
- title: 题名
- responsibility: 责任者
- file_date: 文件日期
- file_year: 年度
- retention_period: 保管期限
- security_level: 密级
- archive_type: 档案类型
- page_count: 页数

# 智能提取内容
- content_text: 提取的文本
- summary: 自动摘要
- keywords: 关键词
- tags: 标签
- embedding: 向量嵌入

# 数字化信息
- is_digitized: 是否已数字化
- file_path: 存储路径
- file_format: 文件格式
- scan_resolution: 扫描分辨率
```

## 🚀 使用流程

### 1. 初始化档案结构
```
1. 创建全宗（如："达天科技"）
2. 创建目录（如："2023年度-文书档案-永久"）
3. 创建案卷（可选，用于卷内文件管理）
```

### 2. 批量数字化
```
1. 选择全宗和目录
2. 拖拽或选择文件（支持PDF/Word/Excel/图片）
3. AI自动处理：
   - 内容提取
   - 关键词生成
   - 摘要生成
   - 标签分类
   - 档号生成
4. 查看处理结果
```

### 3. 档案检索
```
1. 输入关键词
2. 可选筛选：全宗、目录、年度、类型
3. 查看检索结果（含相似度分数）
4. 点击档案查看详情
```

### 4. 档案借阅
```
1. 查找需要借阅的档案
2. 提交借阅申请
3. 等待审批
4. 查看借阅记录
```
